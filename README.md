## 🚀 Featured Engineering Projects

### 🏭 AutoForge: Enterprise Smart Manufacturing Data Intelligence Platform
*A highly available serverless telemetry platform processing 243K+ sensor events across 24 industrial assets.*
- **Architecture:** Engineered real-time data ingestion, validation, diagnostics, and ETL pipelines utilizing Event-Driven principles.
- **Data & Analytics:** Built explainable diagnostics, machine health scoring systems, and dynamic digital twin dashboards for immediate operational insights.
- **Infrastructure:** Provisioned robust, scalable cloud infrastructure as code (IaC) utilizing Terraform.
- **Tech Stack:** `AWS Kinesis` `AWS Lambda` `AWS Glue` `Amazon Athena` `Amazon S3` `Terraform` `FastAPI` `React` `Docker`

### 🔒 SecureShare
*A secure, time-limited distributed file-sharing architecture.*
- **Architecture:** Designed serverless file uploads utilizing S3 pre-signed URLs to offload backend compute and maximize scalability.
- **Security:** Implemented a stringent least-privilege IAM architecture to protect data access and enforce security compliance.
- **Tech Stack:** `React` `Node.js` `Express.js` `Amazon S3` `AWS IAM`

### 💬 Serverless Real-Time Chat Application
*A fully serverless, highly concurrent real-time messaging platform.*
- **Architecture:** Architected a stateful real-time chat system utilizing WebSockets mapped to API Gateway.
- **Data & Security:** Designed a DynamoDB table schema for highly performant messaging persistence and secured API endpoints with robust JWT authentication.
- **Tech Stack:** `AWS Lambda` `API Gateway` `Amazon DynamoDB` `WebSockets` `React` `Node.js`
